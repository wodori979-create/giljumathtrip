# 길주초 6학년, 여행중!

6학년 1반~5반 고정 교실을 제공합니다. 선생님은 반별 비밀번호로, 학생은 반 선택 후 이름을 입력하여 입장합니다. 운영 앱과 로컬 에뮬레이터의 계정·자료는 분리합니다.

6학년 수학여행용 교사·학생 웹 앱입니다. Firebase Spark **무료 요금제**의 Hosting, Authentication, Firestore와 Cloudflare Workers **Free**의 푸시 발송 서버를 사용합니다. 결제 계정, Cloud Functions, Cloud Run, Cloud Storage는 필요하지 않습니다.

앱 주소: https://gilju-grade6-trip-2026.web.app

## 제공 기능

- 선생님/학생 선택 → 6학년 1반~5반 선택 → 교사는 반별 4자리 비밀번호, 학생은 이름을 입력하여 입장합니다. 임의 반 만들기와 참여 코드 입력은 제거했습니다.
- 5개 반은 서로 다른 교사 UID와 Firestore 문서 경로를 사용합니다. 일정·미션·제출 사진·진행 상황·소집 안내·알림 구독을 반별로 분리하고, 해당 반 교사와 참여 학생만 접근할 수 있습니다. 같은 이름의 학생도 Firebase UID로 구분하여 서로 덮어쓰지 않습니다.
- 일정: 1~3일차 시간·일정 이름·활동 장소·소집 장소. 교사는 일정별 미션을 추가합니다.
- 미션: 일정의 미션이 자동 표시됩니다. 학생은 사진을 제출·교체·삭제하고 완료 표시를 할 수 있습니다. 제출 사진은 본인과 교사만 읽습니다.
- 모여라!: 교사가 장소 이름을 직접 적고 사진·모이는 시간·안내 글을 보내면 학생 앱의 알림함에 실시간 표시됩니다. 확인 표시와 지난 안내도 보관됩니다.
- 학생이 ‘휴대폰 알림 켜기’를 누르고 허용하면 백그라운드 Web Push도 받습니다. 알림에는 소집 장소·시간·안내 글이 표시되고, 누르면 앱에서 장소 사진까지 확인합니다. 아이폰은 iOS 16.4 이상에서 Safari로 홈 화면에 추가하고, 추가된 앱에서 알림을 켜야 합니다.
- 교사의 발송 결과는 푸시 서비스가 발송 요청을 수락한 기기 수입니다. 학생이 실제로 읽었는지는 ‘확인했어요’로 확인합니다. 인터넷, 알림 권한, 기기 절전·방해금지 설정에 따라 도착이 늦거나 소리가 나지 않을 수 있습니다.

## 구조와 데이터 보호

React + TypeScript + Vite 정적 앱입니다. Firebase Authentication의 반별 교사 비밀번호 인증과 학생 익명 인증을 사용합니다. 실제 이메일 입력 대신 교실 식별자로 내부 로그인 계정을 생성합니다. 4자리 입력은 반 식별자를 포함한 SHA-256 형식으로 인코딩하여 Firebase 인증에 전달합니다. 이는 Firebase 자격 증명 형식을 맞추기 위한 것으로, 4자리 비밀번호의 추측 난도를 높이지는 않습니다. 비밀번호 원문이나 정답 목록은 앱 번들에 포함하지 않고 무시된 로컬 설정에서만 초기 계정을 준비합니다.

데이터는 Firestore의 `sparkTrips/{교실 식별자}` 아래에 저장합니다. 보안 규칙이 반 참여 여부와 교사 소유권, 학생 UID를 확인합니다. 학생은 반을 고르고 이름을 입력해 참여하며, 다른 반 자료와 다른 학생의 미션 사진 접근을 차단합니다. 제출 사진에는 가입 문서와 일치하는 학생 이름을 기록하여 교사가 제출자를 확인할 수 있습니다.

사진은 브라우저에서 최대 960px·180KB JPEG로 축소하여 원본 위치 등 메타데이터를 제거한 뒤 Firestore에 저장합니다. 장소 사진은 해당 반에 공유되고 미션 사진은 본인/교사에게만 제공됩니다. 실시간 리스너를 사용하여 반복적인 전체 자료 조회를 줄였습니다. Firebase 무료 사용량 한도는 적용됩니다.

Firebase 웹 설정의 `apiKey`는 브라우저 앱을 식별하는 공개 설정입니다. 자료 접근 권한은 Authentication과 Firestore 보안 규칙으로 보호합니다. 관리자 키, 로그인 토큰, 학생 사진, 로컬 에뮬레이터 데이터는 저장소에 넣지 않습니다.

푸시 서버는 Firebase 교사 ID 토큰의 서명·발급자·프로젝트·만료를 확인하고 Firestore의 반 소유권을 다시 검사합니다. 내용과 수신 기기는 보호된 Firestore에서 읽으며 호출자가 임의로 지정할 수 없습니다. Firebase 관리자 서비스 계정은 사용하지 않습니다. 발송용 VAPID 개인키는 Cloudflare Secret에만 배포하며 앱에는 공개키만 넣습니다. 학생 구독 정보는 본인과 해당 반 교사만 읽습니다. 로그아웃하면 구독과 반 참여를 해제합니다.

Cloudflare Workers Free의 일 100,000 요청·요청당 CPU 10ms 제한을 고려해 한 번에 5대씩 발송합니다. 교사는 발송 결과가 표시될 때까지 화면을 유지하세요. 실패 시 10분 안에 ‘푸시 다시 보내기’를 누르면 이미 발송한 기기는 제외합니다. 무료 한도를 넘으면 발송이 제한되며 유료 요금제로 자동 전환하지 않습니다.

## 로컬 개발

Node.js 22 이상, Firebase CLI, Java 21 이상이 필요합니다.

```sh
npm ci
npm run build
npm run emulators
```

다른 PowerShell 창에서 5개 로컬 교실을 준비하고 실행합니다:

```powershell
npm run setup:local
npm run dev
```

http://127.0.0.1:5173 에 접속합니다. 에뮬레이터 프로젝트는 `demo-gilju-trip`이며, 개발 서버는 기본적으로 로컬 Auth·Firestore만 사용합니다. 현재 `.env.local`에도 로컬 사용을 지정했습니다. 로컬에서는 실기기 푸시 발송 서버를 호출하지 않습니다. 소집 안내는 해당 반의 모여라! 탭에서 실시간 확인합니다.

`.env.local`의 `LOCAL_CLASSROOM_PINS_JSON`에 1반~5반 비밀번호를 설정합니다. 이 변수는 `VITE_` 접두사가 없어서 브라우저에 노출되지 않으며 Git에서도 제외합니다. 초기화 명령은 두 개의 명시된 `demo-` 로컬 프로젝트에서만 실행되고, 이미 있는 교실 데이터는 보존합니다. 에뮬레이터는 종료 시 `work/local-emulator-data`로 내보내고 재실행 시 불러옵니다. 해당 로컬 데이터도 Git에서 제외됩니다.

서버를 종료하기 전에 `npm run backup:local`로 명시적으로 백업할 수도 있습니다. Windows의 폴더 이동 제한으로 Firebase CLI의 마지막 단계가 실패하면 완성된 임시 내보내기를 안전하게 복사합니다. 임시 내보내기 폴더도 Git에서 제외합니다.

## 검증과 배포

```sh
npm run test:local
npm run test:classrooms
node --test scripts/test-push-sw.mjs
npm --prefix push-worker ci
npm --prefix push-worker run check
```

검증 명령은 실행 중인 로컬 에뮬레이터의 별도 테스트 프로젝트만 사용합니다. 5개 교사 로그인, 다른 반 비밀번호 거절, 이름 필수 입력, 반별 일정·사진·미션·소집 안내 분리, 제출자 이름 검증, 로그아웃 후 접근 차단을 검사합니다. 사용자가 로컬에서 작성하는 교실 자료를 지우지 않습니다.

배포 시에는 실제 Firebase에 5개 교사 계정·교실을 먼저 준비하고 새 규칙과 앱을 함께 반영합니다. `scripts/setup-production-classrooms.mjs`는 비공개 환경 변수 `CLASSROOM_PINS_JSON`(또는 로컬 설정 변수)에서 비밀번호를 읽고, `--project=gilju-grade6-trip-2026 --confirm-live`를 명시해야 실행됩니다. 기존 계정은 지정 비밀번호로 인증하고 기존 자료를 보존합니다. 소유권이 다르면 덮어쓰지 않고 중단합니다. 로컬 초기화 스크립트는 운영 프로젝트에서 실행되지 않습니다.

사용자가 배포를 승인한 경우 운영 준비 후 `npm run deploy`로 Firestore 규칙/인덱스와 Hosting을 반영합니다. 교실 초기화와 배포는 결제 설정을 변경하지 않습니다. 개발 중인 자료·시험 사진·에뮬레이터 계정을 운영으로 복사하지 않습니다.

푸시 서버 배포는 [push-worker/README.md](push-worker/README.md)를 따릅니다. `lib/push-config.json`에는 서버 URL과 공개키만 저장합니다. 개인키·Wrangler 로그인 설정은 GitHub에 올리지 마세요.

학생의 진행 상황과 사진은 브라우저의 익명 로그인에 연결됩니다. 로그아웃하거나 브라우저 데이터를 지우면 학생의 이전 로그인으로 자동 복구되지 않습니다. 여행 중에는 같은 브라우저로 사용하세요.
